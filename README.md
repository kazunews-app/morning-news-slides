# TREND NEWS — リアルタイム トレンドニュースサイト

**国内・総合 / テクノロジー・AI / ビジネス・経済** の最新トレンドニュースを 1時間ごとに自動収集・要約し、ニュースポータルサイト形式で閲覧できる Web アプリです（GitHub Pages + GitHub Actions で完全自動運用）。

## 主な機能

- **ニュースサイト形式のレイアウト**: トップピックアップ＋速報リスト＋記事カード一覧で見やすく表示
- **マルチソース収集**: Google News（国内・テクノロジー・ビジネス）、はてなブックマークIT、Zenn トレンドから自動取得
- **AI 要約＆記事リーダー**: 記事をクリックすると「概要」「3つの要点」「注目ポイント」をモーダルで素早く確認可能（`GEMINI_API_KEY` 設定時）
- **検索・絞り込み**: カテゴリタブ、注目キーワードタグ、キーワード検索で即座にフィルタ
- **1時間ごとの自動更新**: GitHub Actions により毎時05分に自動更新（PCの電源がオフでも稼働）
- **スマホ完全対応**: レスポンシブUI・ダークモード対応・iPhone「ホーム画面に追加」で全画面アプリ風表示

## ファイル構成

- `index.html` / `css/style.css` / `js/app.js` — ニュースサイトUI本体
- `data/news.js` — 自動生成されるニュースデータ
- `scripts/update_news.py` — ニュース収集・OGP画像抽出・Gemini要約スクリプト
- `.github/workflows/update-news.yml` — 1時間ごとの GitHub Actions 自動更新設定
- `scripts/start_server.ps1` — ローカル確認用サーバー
