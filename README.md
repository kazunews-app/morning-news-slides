# TREND NEWS — リアルタイム トレンドニュースサイト

**国内・総合 / テクノロジー・AI / ビジネス・経済 / 芸能・エンタメ / サブカルチャー / 天気** の最新トレンドニュース（公開から24時間以内の記事のみ）を 5分ごとに自動収集・要約し、ニュースポータルサイト形式で閲覧できる Web アプリです（GitHub Pages + GitHub Actions で完全自動運用）。

## 主な機能

- **ニュースサイト形式のレイアウト**: トップピックアップ＋速報リスト＋記事カード一覧＋テキスト一覧で見やすく表示
- **24時間以内フィルタ & 実画像抽出**: 公開から24時間以内の記事のみを対象とし、記事内のOGP・JSON-LD・本文画像（未取得時は関連Web画像）を表示
- **マルチソース収集**: Yahoo!ニュース、はてなブックマーク、Zenn トレンド、AUTOMATON、ナタリー、PANORA から自動取得
- **日本全国の天気マップ**: Open-Meteo 一括取得＋気象庁（JMA）API＋事前データの3段フォールバックで主要11都市と現在地の天気を常時表示
- **スマホ完全対応**: 左右スワイプでのジャンル切替・プルリフレッシュ時のジャンル維持・ダークモード対応

## ファイル構成

- `index.html` / `css/style.css` / `js/app.js` — ニュースサイトUI本体
- `assets/japan-map.svg` — 天気セクション用の日本地図SVG
- `data/news.js` — 自動生成されるニュース・天気データ
- `scripts/update_news.py` — ニュース収集・画像抽出・天気取得・Gemini要約スクリプト
- `.github/workflows/update-news.yml` — 5分ごとの GitHub Actions 自動更新設定
- `scripts/start_server.ps1` — ローカル確認用軽量Webサーバー
